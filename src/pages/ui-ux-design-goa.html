Good design starts with the user

Interface work is most useful when it begins with the decisions a visitor is trying to make, not a visual style alone.

  • Understand the userAudience needs, tasks and questions guide the structure before any screen is styled.
  • Design the flowJourneys and layouts are planned so the path to a useful action stays clear.
  • Build for accessContrast, focus states and readable type are treated as part of the design, not extras.

UI and UX design questions

What is the difference between UI and UX?

UX shapes structure, journeys and how a site helps a visitor complete a task, while UI is the visual interface layer of type, colour, spacing and components.

Do you design before development starts?

Yes. Research, structure and interface design are planned with implementation in mind so approved layouts translate into responsive front-end components.

Is accessibility part of the design?

Contrast, focus states, labels and readable type are treated as design decisions rather than extras added at the end of the project.
