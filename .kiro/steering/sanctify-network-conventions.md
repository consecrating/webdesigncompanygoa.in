# Sanctify Network Conventions (learned from socialmediamarketingagencygoa.in)

`webdesigncompanygoa.in` is part of the same Sanctify network as
`socialmediamarketingagencygoa.in`. That sister site is the reference for how this
network builds and scales. Align with it, adapted to web design/development intent.

## 1. Scale via a programmatic Service × Industry × Location matrix
The sister site reaches ~500 URLs with a repeatable taxonomy:
- Flat: `{service}-in-{location}`, `{service}-for-{industry}`
- Hubs: `{service}/{location}`, `{service}/for-{industry}`
- Deep combo: `{service}/for-{industry}/{location}`
- ~16 Goa locations: goa, panjim (panaji), mapusa, margao (madgaon), vasco-da-gama,
  porvorim, ponda, calangute, candolim, baga, anjuna, vagator, morjim, palolem,
  colva, benaulim
- ~15 industries: automobile dealers, beach shacks & bars, casinos & nightlife,
  education & coaching, fitness & yoga, healthcare clinics, hotels & resorts,
  professional services, real estate, restaurants, retail boutiques, spa & wellness,
  travel & tour operators, water sports & adventure, wedding & event planners

For web design, the service axis is the existing set (website design/development,
ecommerce, redesign, maintenance, WordPress, UI/UX, speed, landing pages).
The "501 pages" target is met by this matrix: services + industries + locations + blog.

**Quality guardrail:** the reference pages are largely template-token pages (industry
and location names substituted into shared copy + shared stats/process/FAQ/contact).
To do better than the reference and reduce thin/doorway risk, each generated page must
carry genuine per-page specifics (real local context, industry-specific feature needs,
distinct FAQs), not just a swapped town name.

represents the web-design brand.** Client logos, testimonials and case-study metrics
must be web-design-specific (or clearly cross-brand) — confirm which apply before use.

## 3. Voice and proof
- Confident, plain-English, anti-jargon, honest ("a strategist, not a salesperson";
  "no contracts"; "we'll tell you honestly if we can help").
- Proof-led, NOT evidence-hedged: show rating, years, named clients, testimonials,
  case-study metrics, and transparent pricing tiers — using real, approved figures.
- Primary CTA: free consultation / website audit.

## 4. Homepage / page IA to mirror
Hero (rating + since 2012 + stat counters) → client logos → services ("one team,
one invoice") → work/case studies with metrics → 4-step "how we work" (30 days) →
why-Goa + founder quote → industries grid → testimonials → published pricing tiers →
FAQ → contact (email, phone/WhatsApp, studio NAP, hours, enquiry form:
name/business/email/phone/budget/goal + "no lists/newsletters" reassurance).

## 5. Still do NOT
- Invent client names, testimonials, metrics, or pricing that the owner has not
  approved for the web-design brand. Use the sister site's *format*, real web-design
  *facts*.
