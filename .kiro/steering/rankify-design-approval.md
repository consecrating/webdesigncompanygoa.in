# Rankify design and deployment approval

These rules apply to every design or production task for `webdesigncompanygoa.in`.

1. The user-uploaded Rankify ZIP and `https://www.digitalmarketingagencygoa.com/` are the authoritative visual references. A redesign must reproduce their layout anatomy, section rhythm, typography scale, spacing, navigation treatment, image presentation, component shapes, and motion language. Do not replace that direction with a generic agency template or a loosely inspired interpretation.
2. Preserve the specialist site's approved SEO routes and neutral, verified wording, but do not describe generated route outputs as individually designed pages unless each page received a deliberate visual composition.
3. Before changing production, publish a browser-viewable preview from a review branch and give the user the verified review URL. Production is frozen until the user explicitly approves that visual preview and then explicitly authorizes deployment.
4. An instruction to build, redesign, commit, or push is not deployment authorization. FTP upload requires a separate explicit deploy instruction after preview approval.
5. Every production change requires a verified backup and rollback path. Never overwrite or remove the previous production artifact without preserving it first.
6. Never deploy the raw ZIP wholesale. Audit it first and use only the approved visual assets and layout code; exclude handlers, credentials, subscriber data, nested archives, and unrelated server files.
